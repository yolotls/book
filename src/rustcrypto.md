# RustCrypto

Rustcrypto is an example crypto config & processor: [crypto/rustcrypto](https://github.com/yolotls/yolotls/tree/main/crypto/rustcrypto)

It provides no_std & no_alloc cryptography that we provide in our examples through it's implementation of CryptoConfig.

You can find rustcrypto primitives from here: [https://github.com/rustcrypto/](https://github.com/rustcrypto/)

In addition we use curve25519-dalek which can be foiund from here: [https://github.com/dalek-cryptography/curve25519-dalek](https://github.com/dalek-cryptography/curve25519-dalek)
